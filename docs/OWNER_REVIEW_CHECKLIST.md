# Owner review checklist

Branch: `phase4-6/real-risk-stack`

## Local preview

```powershell
cd frontend
npm install
npm run dev
```

Open the Vite URL. The top action buttons are on the dark strip. The Leaflet
basemap/layer selector is intentionally below that strip and has a dark
background on bright map styles.

## PWA check

Use Chrome/Edge DevTools > Application > Manifest and Service Workers. The
manifest is generated by `vite-plugin-pwa`, the app is standalone, and the
field-report shortcut opens `/field-report`.

## Offline field report check

1. Open `/field-report`.
2. Allow location or enter a device location through the browser.
3. Attach a camera/gallery image.
4. Turn the browser offline and submit.
5. Confirm the report says it is saved locally.
6. Restore connectivity and confirm the queue retries.

Images are queued in IndexedDB. They are not claimed as OpenCV/AI verified.

## Official contact reference check

`GET /contacts/official` returns source-attributed reference contacts,
including India's `112` emergency number and NDRF Headquarters control-room
numbers. The endpoint is reference-only and never automatically dispatches.
Use a verified recipient number in `ALERT_TEST_TO` for a Twilio demo.

## Safety claims

The demo must not claim that Kafka, physical sensors, IMD/ISRO live feeds,
cloud/radar tiles, OpenCV verification, or calibrated ML probabilities are
active unless their status is explicitly `ONLINE`/configured and the relevant
credentials or hardware are present.
